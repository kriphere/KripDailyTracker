# Krips Daily Tracker

A static wellness dashboard for tracking daily calories, mood, and energy levels.

## Features

- Save daily calorie, mood, and energy entries
- View summaries for average calories, average energy, and common mood
- Toggle dark mode
- Filter entries by date range
- View a simple calorie trend chart
- Export entries as CSV
- Delete or clear saved entries

## Files

- `index.html` — app page

## GitHub Pages setup

1. Push this folder to a GitHub repository.
2. In GitHub, open the repo and go to Settings > Pages.
3. Set the source to **Deploy from a branch**.
4. Choose the branch (usually `main`) and folder `/root`.
5. Save.

Your app will be available at:

`https://<your-username>.github.io/<your-repo-name>/`

This app uses browser `localStorage`, so entries stay saved on the same device/browser.
